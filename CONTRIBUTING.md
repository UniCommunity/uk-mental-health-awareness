# Contributing

- No methods of suicide or self-harm.
- Prefer NHS, NICE, NIHR, DHSC, Public Health Scotland/Wales, DoH NI, and named UK charities.
- Flag which **nation** a fact applies to.
- Keep crisis numbers at the top of the README.
- Open issues as `correction:` with a source URL.

If you are in crisis, use 116 123 or 111 — not GitHub issues.
